# thoughts/ — the brain dump

Raw capture. This folder is **ignored by Quartz** (never becomes a page on 2bytesgoat.com)
but **is public on GitHub** — don't put secrets here, just don't worry about polish.

## The pipeline

1. **Dump** — throw one line into `INBOX.md`. Zero formatting. `Idea: / Read: / Built: / Asked: / Cool:`
2. **Compost** — periodically (weekly-ish) the ideas get reviewed: post-worthy ones get tagged
   and moved into `meta/IDEAS.md`; the rest stay here as notes.
3. **Publish** — greenlit ideas become `draft: true` posts somewhere in `content/`, grow through
   the Goat Standard (`meta/VOICE.md`), pass the definition-of-done, ship.

Rule of thumb: if people asked you about it IRL, it's post material. If it's just for you, it stays a note.
